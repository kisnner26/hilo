# propuesta para el equipo

## mensaje corto para el grupo

> para los que tengan ia de paga (claude code o codex): armé una app que junta clickup y github y te dice qué te toca hoy, revisa tu pr con el formato acordado antes de abrirlo y te deja listo el comentario de entrega. la idea es que casi no haya vueltas de revisión, porque nos quedan dos semanas.
> es opcional y no pide claves de api: usa tu suscripción. conectas github y clickup una sola vez y listo.
> descarga: {enlace del release}

## cómo se cuenta cuánta gente la instaló

cada descarga del release se registra en github. en la app, ajustes, conexiones, instalaciones muestra las descargas por versión. son descargas, no usuarios activos: la app no manda datos de uso.

## qué le pedimos a quien la pruebe

1. conectar github y clickup
2. abrir "mi día" y decir si lo que le sugiere coincide con lo que le toca
3. correr "revisar pr" sobre su pr antes de abrirlo
4. avisar de cualquier cosa rara en el grupo o en un issue del repositorio de hilo

## lo que todavía puede fallar

- windows y linux no se probaron en una máquina real
- el reparto entre integradores y las rondas son aproximaciones
- las líneas del plan son estimaciones por tipo de tarea
